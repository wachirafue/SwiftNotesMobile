# 📱 SwiftNotesMobile

A fast, responsive, and cross-platform mobile note-taking application built with **React Native** and **Expo**. 

This project demonstrates the ability to build mobile applications for both iOS and Android from a single codebase, focusing on clean UI and smooth performance.

## ✨ Key Features
- 🚀 **Cross-Platform:** Runs seamlessly on both iOS and Android.
- 🎨 **Modern UI:** Clean and intuitive user interface.
- ⚡ **Fast Performance:** Optimized rendering using React Native.

## 🛠️ Tech Stack
- **Framework:** React Native, Expo
- **Language:** TypeScript, JavaScript
- **Tools:** Node.js, Git, VS Code

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing.

### Prerequisites
- Node.js (v18 or newer)
- npm
- Expo Go app on your physical device (or iOS Simulator / Android Emulator)
